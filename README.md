# Laundry Services Website

## Project Description

Laundry Services is a simple and responsive website created using HTML and CSS. It provides a clean and attractive interface for a laundry service website.

The website includes a navigation bar, laundry service information, a booking button, and a laundry-related image.

## Features

* Responsive navigation bar
* Logo section
* Home, Services, About Us, and Contact Us links
* Username button
* Attractive hero section
* Laundry service description
* Book a Service button
* Laundry image
* Responsive design for desktop, tablet, and mobile devices

## Responsive Design

The website is designed to work on different screen sizes.

* **Desktop:** Two-column layout with content and image.
* **Tablet:** Adjusted font sizes, spacing, and image size.
* **Mobile:** The content is arranged vertically and navigation links are hidden.

### Navigation Bar
